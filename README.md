simple-web-app
A minimal static web application built with HTML, CSS, and JavaScript. It includes a lightweight Dockerfile so you can containerize and serve the app easily, and it’s ideal for quick demos, interviews, or DevOps practice. (Repo files observed: index.html, style.css, script.js, Dockerfile, .github/workflows/) [github.com]
✨ Features

Simple, framework‑free HTML/CSS/JS structure that’s easy to read and extend. [github.com]
Container-ready with a Dockerfile for portable, reproducible runs. (General Dockerfile usage) [docs.docker.com]
Deployable as a static site (e.g., GitHub Pages) in minutes. [docs.github.com]
